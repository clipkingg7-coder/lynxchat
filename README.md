# LYNX CHAT v3 🐆

Talk to strangers — **video + voice + text**, with country matching, flags, and a **soundboard**.

## What's new in v3
- 🔊 **Built-in soundboard** — 8 funny sounds (Airhorn, Tada, Applause, Boo, Siren, Rimshot, Fart, Sad Trombone). Synthesized in the browser, **no sound files needed, never breaks**. Both you AND your match hear it.
- Everything from v2: working two-way camera + mic, one-tap toggles, country flags, worldwide/same-country matching, text chat.

## Deploy to Render (free)
1. Upload all files in this folder to your GitHub repo **root** (including the `public/` folder).
2. Render → New Web Service → connect the repo.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Root Directory: *(leave blank)* → Create.

## Run locally
```
npm install
npm start
```
Then open http://localhost:3000 in two tabs to test.

> Camera & mic only work on **HTTPS** (Render provides this) or `localhost`.
